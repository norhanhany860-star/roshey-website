# roshey-website
Handmade crochet bags website built with HTML, CSS, and JavaScript.
ROSHEY 🌸

A simple, responsive website for ROSHEY, a small business that sells handmade crochet bags. Customers can browse the bags, see their prices, colors, and discounts, and place an order through the brand's WhatsApp or Instagram.

Live demo: https://norhanhany860-star.github.io/roshey-website/

About the Project

This website was built for a real client who makes crochet bags by hand and needed a clean online catalog for her brand. The project was developed as a university assignment for the Software Engineering course and follows the Waterfall model (SDLC).

The client's main goals were:

A simple, easy-to-use design where the bags are the focus.
Light colors that match the brand logo.
Only the client's own photos (no external images).
Direct ways to contact the brand and place orders.
Features
Product catalog: every bag is shown with its photo, name, and price.
Available colors: color dots show the colors each bag can be made in.
Discounts: selected bags display a discount badge, the old price (crossed out), and the new price.
Order popup: choosing "Order now" opens a window to pick a color and add optional notes (size, initials, color mix).
Ordering via WhatsApp or Instagram: a ready-made message with the bag name and color is sent to the brand's account.
Custom order section: customers can describe a bag of their own design and send it to the brand.
Contact button: a direct link to the brand's Instagram from the home page.
Responsive design: works on mobile phones and desktop screens.
Sticky navigation bar with smooth scrolling to each section.
Technologies Used
Technology	Purpose
HTML5	Page structure and content
CSS3	Styling, Flexbox, CSS Grid, media queries
JavaScript (Vanilla)	Rendering product cards from data, popup window, order messages
Google Fonts	Fraunces, DM Sans, and Cormorant Garamond

No frameworks or external libraries are used. The site is fully static (no backend and no database), and no customer data is stored.
